# conformance

The conformance suite every go-term engine is scored against. The expected states ("goldens") are generated by upstream,
unmodified xterm.js headless; go-term follows its behaviour and is never a fork of it.

| ref | package | role |
|---|---|---|
| `xcur` | `@xterm/headless@6.0.0` | the release Studio's page runs; **the gate** (`conformance/goterm` `TestGateXcur`) |
| `x53` | `xterm-headless@5.3.0` | the page's earlier release; reported only (docs/decisions/0003-engine.md) |

Both are pinned in `gen/pins.lst` (tarball URL + sha512 integrity), `gen/package-lock.json` and `gen/pins.json`
(installed versions, bundle sha256, runtime option defaults, public modes keys, lockfile sha256). The unicode11 addons
for each ref are pinned but unused: the goldens use the default unicode v6 widths.

## Running it (Docker only, no network inside the containers)

```sh
bash conformance/scripts/fetch-pins.sh                                        # host: curl the tarballs, check sha512
bash conformance/scripts/node.sh conformance/gen 'npm ci --offline --ignore-scripts'
bash conformance/scripts/node.sh conformance 'sh scripts/regen-check.sh'      # regenerate twice, compare with golden/
bash conformance/scripts/go.sh . 'go test ./conformance/...'
bash conformance/scripts/go.sh . 'go run ./conformance/cmd/conformance -engine goterm'   # the gate: xcur, 314/314
bash conformance/scripts/go.sh . 'go run ./conformance/cmd/conformance -engine stub -ref x53'
bash conformance/scripts/go.sh . 'go run ./conformance/cmd/conformance -count'
```
`node.sh`/`go.sh <workdir> '<command>'` run one foreground container from the pinned image digest: `--network none`,
the repo read-only except `conformance/`, and caches under `CACHE`. Globs expand inside the container.
Selftests: `node.sh conformance/gen 'node selftest.mjs <suite>'` for case, cells, snap, probe, probe2, writer, raw, split, diff.

## Layout

- `cases/<category>/<name>.json`: one case per file. `{"id": "<category>/<name>", "desc", "cols" (20), "rows" (6),
  "scrollback" (headless default), "unicode" ("6"), "tags", "steps": [...]}`. Each step is `{"w": "<text, written as UTF-8>"}`,
  `{"x": "<hex bytes>"}` (raw/invalid bytes), `{"resize": [cols, rows]}` or `{"reset": true}`.
- `golden/<ref>/<category>/<name>.json`: a header (`id`, `ref`, `init`, `inSha`, `pins`), then one snapshot after every step:
  `op` (with `in`, the hex of the exact bytes `term.write` received), `P`, `text` and `cells` (one line per row), `attrs`, `I`.
  Then `B` (probe results) and `split`. Keys are sorted and every grid row is on its own line, so a diff shows the changed rows.
- `golden/diff.json`: every path where x53 and xcur differ, by tier. This is the list of reference splits.
- `golden/manifest.json`: pins.json sha, image digest, generator and case file shas, split-sensitive cases.
- `probes.json`: the probe byte sequences, shared by the generator and the Go runner.
- `gen/`: the node generator (`gen.mjs`), pin producer/checker (`make-pins.mjs`, `verify-pins.mjs`), selftests.
- `runner/`: the Go scorer; `cmd/conformance`: its CLI.
- `goterm/`: the adapter for go-term's own engine (`vt/`), read natively, and `TestGateXcur`, the gate.

## What is compared

- **P** (public xterm.js API, scored): `buffer.normal/alternate` lines through `getLine`/`getCell` (`getChars`, `getWidth`,
  colour mode + value, `isBold` … `isOverline`), `isWrapped`, `cursorX/Y` (x == cols means wrap pending), `baseY`, `viewportY`,
  `buffer.active.type`, `terminal.modes`, `options.cursorStyle/cursorBlink`, `onTitleChange`, `onBell`, `onData` replies, `onLineFeed`.
- **B** (behavioural probes through the public API, scored): four twins replay the case, write CAN, then T1 DECRQM for every
  mode (cursor visibility ?25, mouse encoding ?1006/?1016, …), DECRQSS, CPR, DSR, DA; T2 the tab stops (cursorX after each HT);
  T3 the saved cursor (ESC 8 + CPR); T4 the pen (attrs of `\rX`) and the charset (glyphs of `` `aqx ``).
- **I** (internals `_core.*`, reported, never scored; `null` = unmeasured): cursor hidden, mouse encoding, scroll region,
  unicode version, and per attribute the underline style/colour and OSC 8 link id.
- Every case also runs as split variants: one byte per write, and every two-chunk split of each write when the case writes
  fewer than 512 bytes. A failure there is `SPLIT`. Variants headless itself is sensitive to are recorded (`split.sensitive`).

Options: `new Terminal({cols, rows, scrollback, allowProposedApi: true})`. In both bundles `allowProposedApi` only gates the
proposed-API getters `buffer`, `parser`, `unicode` and `markers` (`_checkProposedApi`) and is read nowhere else, so it is
behaviour-neutral; the harness needs `buffer`. Everything else is the headless default.

Not scored in #1: 7 cases whose distinguishing outcome lives only in tier I, because their P/B result equals the plain case:
`osc/osc8-link` (link id), `sgr/double-underline`, `sgr/ul-curly`, `sgr/ul-dashed` (underline style), and
`sgr/ul-colour-256`, `sgr/ul-colour-rgb`, `sgr/ul-colour-reset` (underline colour). Their I values are in the goldens.

## Fuzz (gh #9)

```sh
bash conformance/scripts/fuzz.sh 600 <seed>     # host go build, then one node container; FUZZ_SHARDS=4 node processes
```
A differential fuzz against `@xterm/headless` 6.0.0 through this harness: `cmd/fuzzgen -seed S -n 100 -root DIR` writes
random cases (geometry 2..60 x 1..20, scrollback 50, writes of ASCII, UTF-8 incl. wide/combining/ZWJ/invalid, C0, CSI, SGR,
DECSET, OSC, DCS, APC and ESC tokens, rare resize and reset; the same seed writes the same files) plus byte copies of
`probes.json` and `gen/pins.json`; `gen/fuzz.mjs --root DIR [--shard I/N | --merge N]` records xcur goldens for them
(gen.mjs's per-case body, no noop check); `conformance -root DIR -engine goterm -fuzz` scores them. `-fuzz` also scores
the split variants headless itself is sensitive to, against the whole-write golden (go-term decodes UTF-8 the same at
every cut, #14), so nothing is skipped, and it drops the per-category minimums; its last line is
`TOTAL <pass>/<cases> PASS|FAIL hsens=<variants scored that headless gets wrong>`. The default CLI and the gate still skip
them. `fuzz.sh` loops batches (seed, seed+1, ...) until the seconds are spent and ends with
`FUZZ seconds= batches= cases= variants= hsens= diffs=`: exit 0 no diff, 1 a diff (that batch kept as
`.cache/fuzz/fail-<seed>`, a root the CLI re-scores), 2 nothing ran or a batch was unmeasured (`.cache/fuzz/bad-<seed>`).
The fuzz is outside `scripts/check.sh` and CI.

## Scoring an engine

Implement `runner.Engine` (`Write`, `Resize`, `Reset`, `Snapshot() (runner.State, error)`) and a `runner.Factory`, then
`runner.Register("name", factory)`. `runner.RunCase` reports `PASS`, `FAIL`, `SPLIT` or `STALE` (a golden whose ops no longer
hash to its `inSha`) with the first mismatching path. The CLI exits 0 when every case passes, 1 on a failure, 2 when something
is unmeasured. `stub` (does nothing) must score 0; `oracle` (replays the goldens) scores 100 % by construction.
